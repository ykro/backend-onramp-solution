# Pista 2. Parámetros en la ruta

Una parte de la ruta entre llaves, como `/saludo/{nombre}`, se convierte en un parámetro de la función con el mismo nombre. Si la función declara `nombre: str`, FastAPI le pasa el texto que venía en la URL. Para armar el saludo, una f-string de Python es suficiente.

`GET /libros` no recibe parámetros. Solo tiene que devolver la lista `LIBROS` que ya está definida arriba en el archivo.

Si quieres ver la forma completa de un endpoint con parámetro, abre [la pista 3](3.md).
