# Pista 1. Dónde se decide cada código de estado

En FastAPI hay dos formas de cambiar el código de una respuesta. Para el caso normal de una ruta, el decorador acepta un parámetro con el código por defecto. Para un error dentro de la función, se lanza una excepción que FastAPI convierte en respuesta. Revisa [Response Status Code](https://fastapi.tiangolo.com/tutorial/response-status-code/) y [Handling Errors](https://fastapi.tiangolo.com/tutorial/handling-errors/).

Para el estado compartido, fíjate dónde viven `_SHARED_BOOKS` y `_NEXT_ID`. Todo lo que está a nivel de módulo existe una sola vez, sin importar cuántas apps crees.

Si ya ubicaste el lugar de cada cambio, abre [la pista 2](2.md).
