# Pista 1. Qué mirar antes de escribir SQL

SQLite trae la verificación de llaves foráneas apagada en cada conexión nueva, por compatibilidad con versiones viejas. Se enciende con una instrucción `PRAGMA` que hay que ejecutar antes de crear las tablas.

Para las consultas, escribe primero un `SELECT` simple sobre `books` en `uv run python` y mira qué devuelve. Después agrega el `JOIN`. `conn.row_factory = sqlite3.Row` ya está configurado, así que cada fila se puede convertir en diccionario con `dict(row)`.

Si ya probaste eso, abre [la pista 2](2.md).
