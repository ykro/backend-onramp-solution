# Pista 2. La forma de cada test

Cada test llama a `paso05_pruebas.calculate_late_fee` (siempre con el prefijo del módulo, así el verificador puede reemplazarla) y compara el resultado con un `Decimal` exacto usando `assert`. Nunca llames a las versiones con un bug desde tus tests; el verificador se encarga del cambio.

- Corre `uv run onramp inspect --paso 5` y marca en la tabla las filas donde cada versión se aleja de la correcta.
- Las dos versiones se equivocan en filas distintas. Si tus tests solo cubren las filas de una, la otra pasa en verde.

Si quieres ver la forma de un test, abre [la pista 3](3.md).
