# Pista 2. La forma de cada test

Cada test llama a `paso05_pruebas.calculate_late_fee` (siempre con el prefijo del módulo, así el verificador puede reemplazarla) y compara el resultado con un `Decimal` exacto usando `assert`.

- Caso normal, varios días de atraso con la tarifa por defecto.
- Caso borde, `0` días y un número negativo, los dos deben dar `Decimal("0.00")`.
- Detección del bug, un caso donde la versión con un bug devuelve otra cosa. Escríbelo contra `calculate_late_fee`, no contra la versión con un bug; el verificador se encarga del cambio.

Si quieres ver un test completo de ejemplo, abre [la pista 3](3.md).
